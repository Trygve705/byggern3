# lab-tools

Utility files for the TTK4155 lab, from the course's Misc. Resources.

- `mcp2515.h`: register constants for the MCP2515 CAN controller
- `sram_test.c`: external SRAM read/write test, `\n` line endings
- `sram_test_cr.c`: external SRAM read/write test, `\r\n` line endings
- `fonts.h`: font bitmaps for the display
- `TouchToPWM.hex`: prebuilt touch-to-PWM firmware for flashing
